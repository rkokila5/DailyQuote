# DailyQuote

A simple SwiftUI iOS app that shows a random motivational quote.  


## Features
- Tap the button to get a new quote
- Simple, clean SwiftUI interface
- Perfect starter project for learning iOS development

## How to Run
1. Open `DailyQuote.xcodeproj` in Xcode
2. Press Run (⌘R) to launch in Simulator or on your device
